# Zen Kitchen

A calm, local-first PWA for batch cooking a Japanese diet — pantry, recipes, cooking sessions, ready food, week plan, shopping, and backup.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Data lives in IndexedDB on your device. Use **More → Backup** to export/import a full JSON snapshot.
